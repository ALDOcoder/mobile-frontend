# Friends.vue GSAP 动画增强

## 目标
为好友页面添加流畅的 GSAP 动画效果，提升用户体验。

## 动画效果

### 1. 列表项入场动画
- 好友列表和请求列表项依次淡入 + 从下方滑入
- 使用 `gsap.from()` + `stagger` 实现交错动画
- 效果：`autoAlpha: 0, y: 20, stagger: 0.05`

### 2. 标签切换动画
- 主标签（好友列表/好友请求）切换时内容淡入
- 子标签（收到的请求/已发送）切换时内容淡入
- 使用 `gsap.fromTo()` 实现平滑过渡

### 3. 下拉刷新动画
- 刷新时列表项重新播放入场动画
- 刷新完成后的加载指示器动画

## 实现方案

### 依赖
- 安装 GSAP：`npm install gsap`

### 代码结构
```typescript
import gsap from 'gsap'

// 列表项入场动画
function animateListItems(selector: string) {
  gsap.from(selector, {
    autoAlpha: 0,
    y: 20,
    duration: 0.4,
    stagger: 0.05,
    ease: 'power2.out'
  })
}

// 标签切换动画
function animateTabContent(el: HTMLElement) {
  gsap.from(el, {
    autoAlpha: 0,
    duration: 0.3,
    ease: 'power1.out'
  })
}
```

### 触发时机
1. `onMounted` → 初始加载时播放列表动画
2. `loadFriends/loadRequests/loadSentRequests` 完成后 → 数据更新后播放动画
3. `van-tab` 切换时 → 通过 `@click` 触发内容动画

## 关键文件
- `src/views/Friends.vue` - 主组件，添加动画逻辑
- `package.json` - 添加 GSAP 依赖
