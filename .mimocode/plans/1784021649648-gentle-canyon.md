# 解决 GitHub 连接问题 (Port 443)

## 问题诊断

| 测试项 | 结果 |
|--------|------|
| DNS 解析 github.com | ✅ 成功 (20.205.243.166) |
| Ping github.com | ✅ 成功 (190ms 平均) |
| HTTP (端口 80) | ✅ 成功 |
| **HTTPS (端口 443)** | ❌ **失败** |
| SSH (端口 22) | ✅ 成功 |
| Windows 防火墙 | ON (所有配置文件) |
| 代理设置 | 无 |

**根本原因**: 端口 443 (HTTPS) 被阻断，很可能是 GFW (防火墙) 或 ISP 级别的封锁。这是中国大陆常见的问题。

## 解决方案

### 方案 1: 配置 Git 代理 (推荐)

如果你有代理/VPN (如 Clash, V2Ray, Shadowsocks 等)，配置 Git 使用它：

```bash
# HTTP 代理 (假设本地代理端口是 7890)
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 或 SOCKS5 代理
git config --global http.proxy socks5://127.0.0.1:7891
git config --global https.proxy socks5://127.0.0.1:7891
```

### 方案 2: 使用 SSH 替代 HTTPS

SSH 端口可用，可以改用 SSH 协议：

```bash
# 将远程 URL 改为 SSH
git remote set-url origin git@github.com:用户名/仓库名.git

# 或克隆时使用 SSH
git clone git@github.com:用户名/仓库名.git
```

### 方案 3: 使用 GitHub 镜像/加速服务

使用 ghproxy.com 或其他镜像加速：

```bash
# 克隆加速
git clone https://ghproxy.com/https://github.com/用户名/仓库名.git
```

### 方案 4: 修改 hosts 文件

添加 GitHub 的 IP 映射 (可能需要定期更新)：

```
# 在 C:\Windows\System32\drivers\etc\hosts 添加
140.82.114.4    github.com
140.82.114.4    www.github.com
185.199.108.153  assets-cdn.github.com
199.232.69.194   github.global.ssl.fastly.net
```

## 验证步骤

1. 测试 HTTPS 连接：`Test-NetConnection github.com -Port 443`
2. 测试 Git 操作：`git ls-remote https://github.com/octocat/Hello-World.git`
3. 如果配置了代理，测试：`curl -I https://github.com`

## 注意事项

- 如果使用代理，确保代理软件正在运行
- 临时解决方案：使用手机热点测试是否为 ISP 问题
- 长期方案：考虑使用 GitHub 镜像服务或稳定代理
